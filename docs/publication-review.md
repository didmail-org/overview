## License inventory evidence and limits

The installed-package inventory found missing license metadata for `@arcblock/did-motif@1.1.14`, `configurable@0.0.1`, `escape-regexp@0.0.1`, and `@realm/fetch@0.1.1`. The installed `did-motif` package has an Apache-2.0 license file; `configurable` and `escape-regexp` state MIT in their READMEs; Realm JS source at the matching tag states Apache-2.0 as described in [Licensing](licensing.md). These observations do not establish complete notice compliance for a built archive. The standalone tracked-file inventory found no `.ttf`, `.otf`, `.woff` or `.woff2` files; dependencies or built artifacts may still include fonts. The prior inventory found license files for all 174 hosted Flutter lock entries and license declarations for 88 locally installed Podspecs, not a review of every native dependency or platform.

One locally tested Chrome ZIP contained no native `.node`, `.so`, `.dylib`, or `.dll` file. That narrows, but does not resolve, the distribution analysis of LGPL libvips and its dependencies in other builds and targets. The Chrome ZIP includes the project LICENSE, NOTICE, patch-specific notices and the Embla license; it does not yet have a verified complete third-party notice bundle. Do not distribute it as a finished release on this evidence alone.

An instrumented extension production webpack build enumerated 2,580 client compiler module paths mapping to 271 package instances; see the [sanitized dependency inventory](https://github.com/didmail-org/extension/blob/main/docs/browser-dependency-inventory.md). This compiler inventory can include modules later removed by optimization and is not a complete cross-platform SBOM. Two instances lacked license metadata (`@arcblock/did-motif@1.1.14` and `jsonpack@1.1.5`); both include license text in the installed package. Nine instances had no local LICENSE/COPYING file; their metadata, source provenance and distribution obligations require review. The upstream tagged MIT license for the three Embla 8.6.0 packages has been added to the extension notice set. The remaining third-party archive notice inventory is incomplete.
