# DIDMail

DIDMail is a decentralized mail project. Its components are maintained in separate repositories:

- [Protocol SDK and specifications](https://github.com/didmail-org/protocol)
- [Server](https://github.com/didmail-org/server)
- [Browser extension](https://github.com/didmail-org/extension)
- [Mobile client](https://github.com/didmail-org/mobile)
- [Desktop client](https://github.com/didmail-org/desktop)

Repository migration and [pre-publication security and licensing review](docs/publication-review.md) are in progress. Some repositories remain private while their reviews proceed. See [repository migration](docs/repository-migration.md) for the component mapping.

Original DIDMail project code and documentation are licensed under [Apache-2.0](LICENSE); see [NOTICE](NOTICE) and individual repositories for third-party terms.

For vulnerability reporting guidance, see [SECURITY.md](SECURITY.md).
