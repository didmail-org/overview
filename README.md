# DIDMail

DIDMail is a decentralized mail project. Its components are maintained in separate repositories:

- [Protocol SDK and specifications](https://github.com/didmail-org/protocol)
- [Server](https://github.com/didmail-org/server)
- [Browser extension](https://github.com/didmail-org/extension)
- [Mobile client](https://github.com/didmail-org/mobile)
- [Desktop client](https://github.com/didmail-org/desktop)

Repository migration and [pre-publication security and licensing review](docs/publication-review.md) are in progress. These repositories may be private or temporarily unavailable while migration proceeds. The historical [monorepo](https://github.com/didmail-org/didmail) is preserved privately.
